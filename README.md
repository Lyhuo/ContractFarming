# Contract Farming Registry

A single-page website listing contract farming companies with crops, hectares and timing.
Add, edit and delete records, search by company or crop, export to Excel or CSV, and upload an Excel or CSV file.

Records are stored in the visitor's browser (localStorage). Use Export and Upload to move data between devices.

## Host on GitHub Pages
1. Create a repository and upload `index.html` to the main branch.
2. Open Settings, then Pages. Under Build and deployment choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
3. After a minute the site is live at `https://<your-username>.github.io/<repository>/`.
